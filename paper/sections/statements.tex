\item It proposed the candidate method and the pre-registered decision rule.
\item It drafted this manuscript and generated its tables and numbers with a script that reads the raw run

unverified by humans.

\subsection*{Reproducibility statement}
The code uses only the Python standard library. The experiment is reproduced with
\texttt{PYTHONPATH=src python3 -m ordertta.stage --stage configs/stage2\_order\_penalty\_diagnostic.json}
at commit \texttt{\res{commit}}. The frozen condition configurations, the stage manifest (code, configuration,
data, model and holdout hashes, CPU time and memory) and the raw per-step logs are included with the code.
All tables and in-text numbers are regenerated by \texttt{python3 paper/scripts/export_results.py} from those
raw files. Appendix~\ref{app:repro} lists the files and the deviations from earlier plans. Synthetic data are
generated from the listed seeds; no external data or pretrained weights are used.
