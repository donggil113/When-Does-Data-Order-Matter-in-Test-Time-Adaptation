\subsection*{Reproducibility statement}
The code uses only the Python standard library. The experiment is reproduced at commit
\texttt{\res{commit}} with
\begin{center}
\small\texttt{PYTHONPATH=src python3 -m ordertta.stage}\\
\small\path{--stage configs/stage2_order_penalty_diagnostic.json}
\end{center}
The frozen condition configurations, the stage manifest (code, configuration,
data, model and holdout hashes, CPU time and memory) and the raw per-step logs are included with the code.
The script \path{paper/scripts/export_results.py} regenerates all tables and in-text numbers from those raw
files. Appendix~\ref{app:repro} lists the files and the deviations from earlier plans. Synthetic data are
generated from the listed seeds; no external data or pretrained weights are used.
